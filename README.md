# TripleTen Data Science Projects (Sprints 1-5)

## Overview

This repository contains projects completed during Sprints 1 to 5 of the TripleTen Data Science Bootcamp.

Throughout these projects, I applied fundamental data analysis techniques using Python and industry-standard libraries. The work includes data preprocessing, exploratory data analysis (EDA), statistical analysis, data visualization, and business-oriented insights derived from real-world datasets.

The objective of these projects was to develop practical skills in data cleaning, analytical thinking, hypothesis testing, and communicating findings through data-driven recommendations.

## Projects Included

### Sprint 1 – Basic Python
- Python fundamentals
- Variables and data types
- Conditional statements
- Loops
- Functions and basic programming concepts

### Sprint 2 – Basic Python (Continuation)
- Advanced Python concepts
- Working with libraries
- Data structures
- File handling
- More complex programming tasks

### Sprint 3 – Data Wrangling
- Data import and inspection
- Data cleaning
- Missing value treatment
- Duplicate handling
- Data transformation and preparation

### Sprint 4 – Data Wrangling (Continuation)
- Advanced data preprocessing
- Exploratory data analysis (EDA)
- Data aggregation and filtering
- Data visualization
- Business-oriented data interpretation

### Sprint 5 – Statistical Data Analysis
- Descriptive statistics
- Hypothesis testing
- Probability concepts
- Data-driven decision making
- Statistical interpretation of business scenarios
